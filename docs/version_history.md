# Version history

## 2.0.0 — Unreleased

Version 2 improves offline voice diagnostics, adds safe application-name
clarification, redesigns the GUI around chat, and organizes existing actions under
More Activities. It preserves the Version 1 database, command, dispatcher, safety,
permission, confirmation, provider, plugin, and local-first boundaries.

See [Version 2 upgrade notes](releases/v2.0.0.md) and the repository
[changelog](../CHANGELOG.md).

## 1.0.0 — Stable source baseline

Version 1 established Omega's typed command/action architecture, deterministic parser,
central safety gateway, Windows application/file/folder boundaries, persistence,
productivity, scheduling, providers, workflows, plugins, local AI, accessibility,
terminal, GUI, offline voice, packaging, CI/CD, and release-readiness checks.

See [Version 1 release notes](releases/v1.0.0.md). Optional hardware, provider,
runtime, model, and clean-machine packaging paths require their own environment tests.
