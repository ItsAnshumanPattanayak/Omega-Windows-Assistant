# Omega 1.0.0

Release-preparation date: 2026-07-29. Expected tag: `v1.0.0`.

Omega 1.0 is the first stable source release of the local, safety-first Windows
assistant. It unifies terminal, tkinter GUI, and optional offline voice inputs with a
typed command lifecycle, central safety gateway, scoped confirmation, local SQLite
persistence, and privacy-minimized results.

## Major capabilities

- Allowlisted application, file, folder, browser, and Windows system operations.
- Recoverable deletion, undo, local history, reminders, alarms, timers, notes, tasks,
  knowledge search, and bounded code-free workflows.
- Optional fake-tested email/calendar provider boundaries, secure reviewed plugins,
  and disabled-by-default local AI proposal generation.
- Explicit clipboard and screenshot utilities without background monitoring.
- Local profiles, accessibility preferences, English localization, and partial Hindi
  preview with deterministic English fallback.
- Security/performance diagnostics, Windows packaging sources, artifact verification,
  SHA-256 manifests, and tag-only release automation.

## Installation and requirements

Omega requires Windows and Python 3.11 or newer for source use. Follow
[installation.md](../installation.md). A portable ZIP or per-user installer should be
used only after the release workflow publishes verified artifacts for `v1.0.0`.
Builds are unsigned and may show an unknown-publisher warning.

Optional voice, browser, email/calendar, plugins, and local AI require explicit local
setup described in their respective documentation. No credential, model, provider,
or plugin is bundled or downloaded automatically.

## Upgrade notes

The per-user data directory and SQLite data are preserved during installer upgrade
and uninstall. Back up important local data before upgrading. Migrations run during
explicit application startup and reject unsupported future schemas safely.

## Privacy and security

Omega performs no telemetry or cloud sync. Exact confirmation is required for scoped
high-impact mutations, and confirmation receipts cannot be replayed for a different
action. Provider content, clipboard text, screenshots, document bodies, AI prompts,
and credentials are excluded from ordinary logs and release artifacts.

## Verify a download

Download the artifact and `SHA256SUMS.txt`, then compare:

```powershell
(Get-FileHash -Algorithm SHA256 .\Omega-1.0.0-windows-x64.zip).Hash.ToLowerInvariant()
Get-Content .\SHA256SUMS.txt
```

The 64-character lowercase digest and exact filename must match. See
[releasing.md](../releasing.md) and [packaging.md](../packaging.md).
